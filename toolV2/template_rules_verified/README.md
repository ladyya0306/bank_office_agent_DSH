# 已复核目标文件的填写位置

此目录随 `D:\DSH\tool\office` 一起复制到另一台电脑。办公工具保存目标文件名、标签文字和“字段填在哪里”的规则；不复制源材料、事实数据库或填好的文件。如果目标文件名或标签本身含客户信息，复制此目录前仍要检查。

使用者复核成品并通过现有 `--sign-confirmed` 流程签核后，工具核对本次预演时的规则没有变化，才把该目标文件的规则保存在这里。下次目标文件内容完全相同，即使文件名改了，也会自动复用；内容有任何变化就不套用旧位置。同一文件的新规则再次签核后，旧版保存在 `history`，新版生效。

文件名相近而内容不同的旧版，只在整理目标文件时提示参考，不能自动填写；需要重新确认新文件的实际位置。

请勿把尚未复核的候选规则或客户资料手工放入此目录。目录中的文件由工具管理；复制部署包时保留整个目录。
