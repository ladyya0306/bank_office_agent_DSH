# toolV2 开发约定

目标是让一次填表由程序连续完成，减少模型反复解析、确认和重跑。旧版 `../tool/office` 只作参考，不能修改用户正在使用的旧版或历史工作区。

- 当前维护主代理负责流程设计、数据正确性、关键问题修复和最终复核；可独立完成，也可按用户授权分派范围明确的子任务。模型名称不构成维护前置条件，报告实际使用的模型。
- 维护入口为 `MAINTENANCE.md`；当前状态为 `../release-docs/maintenance-state.md`。按需读相关文件，不从全部历史会话重新推断现状。
- `office_kit` 是从旧版复制的办公能力；来源见 `engine-origin.json`。优先复用，发现缺陷才针对性修复，不新增另一套 Word/Excel 写入程序。
- `workflow` 负责一次任务的顺序与恢复；DSH 插件负责原生弹窗及继续调用；数据库仍是工作区内的 `db/workflow.db`。
- 用户回答必须由原生弹窗取得；模型不得通过公共工具参数代填答案。CLI 是本地维护接口，不作为身份认证系统。
- 不删库、不清空历史、不覆盖源文件和目标模板。不让代理按旧编号删除规则。位置调整使用已有按模板和字段修改的方法。
- 文件未变、规则未变、批次未变时沿用已有工作。变化时只重问、重做受影响部分。出错返回具体原因，禁止无限自动重试。
- 测试只覆盖改动相关的正常填报、重复调用、变化、取消和部分失败；用合成资料。禁止把用户业务数据上传外网。
- 不将填报完成说成用户已签核，不将日志说成不可篡改，不声称任意模板都可自动处理。
