# 本地启动日志

更新：2026-09-27。仅调整启动日志，不改变 toolV2 填报、权限或审批。

`npm start`、`npm run dev` 和 `node start.js` 的启动器正常输出及 DSH 子进程标准输出/错误，默认同时显示在终端，并保存到：

`deepseek-harness-local/logs/runtime/<启动时间与唯一后缀>/stdout.log` 和 `stderr.log`。

每次启动单独建目录，不覆盖旧日志；路径相对安装目录，与调用者当前目录无关。不自动删除历史记录。日志目录创建失败会明确报错，不启动子进程。

此前人工重定向到安装根目录的 `.log` 集中归档到 `logs/archive/`。以后维护脚本若另外使用 `RedirectStandardOutput`、`RedirectStandardError`，也应指向 `logs` 下的独立目录；外部命令自行指定的重定向位置不受 `start.js` 控制。

已有会话记录及业务数据库仍在原工作区。这些运行日志不替代会话和业务记录，也不代表新增审计或隔离控制。启动输出可能包含本机登录地址，请勿公开上传。已运行进程保持原有输出句柄，新默认位置从下次启动生效。
