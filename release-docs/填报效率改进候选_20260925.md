## 已实现的行为

| 问题 | 候选的行为 | 保留的边界 |
| --- | --- | --- |
| `needs_mapping` 太长 | 来源事实合并别名，只列一次。默认一页来源和第一份模板位置；原工具新增 `mapping_read` 参数按模板/页读取，含原句、【填写处】、候选字段、已有位置及完整上下文入口。过长来源有明确完整文字页。 | 没有新增工具、数据库或要求模型解析的映射文件；不保证任意规模内容永远只需一页。 |
| Excel 标签和值格重复填 | 明确存在右侧带格式空值格时优先值格；保留真实句中空位。旧规则按同模板、同字段、确定标签格关系迁移；原本包含标签格和值格时去重。 | 不确定结构保留局部问题；未用具体模板名或固定坐标决定行为。 |
| 日期区间写到年数空位 | 写入前识别日期区间与固定年月单位不兼容，只把受影响项交给原生确认。可留空或输入该位置适用的值；实际写入也拒绝明显区间错配。 | 不从日期区间自行推算业务期限；没有完整实现所有单位换算或自然语言时间推理。 |
| 同一事实别名重复问 | 按同批次、稳定来源事实、明确主体/关系、用途和数值复用跨表确认；未知主体仍按模板隔离。卡片主体是一句建议，金额证件沿用醒目标记，位置在可折叠详情中。 | 不按“数字相同”合并不同主体或不同用途；不增加每张表必须重问的规定。 |

## 阅读和调用

`office_fill_task` 的原参数仍可用。分页例子（继续同一任务）：

```json
{"work":"本次办公工作区","task_id":"已有任务编号","mapping_read":{"section":"positions","template":"target/模板.docx"}}
```

`mapping_pages` 或 `mapping_page` 的 `next` 不为空时原样作为下一次 `mapping_read`。`fields` 读来源，`templates` 读模板清单，`context` 加模板与 `slot_id` 读完整位置原文，`issues` 读问题。只读分页不重新解析、不填写、不提问。位置提交与只读分页分开调用；来源/规则变化后旧页版本失效。

`delivery.attachment_groups` 是当前交付分组；`versions` 中 `current` 为当前版，`previous` 为新版未成功的旧版，`superseded` 为已被替代版，`historical` 为其它历史记录。

## 启用与回退

候选的源码、测试、分支和必要本地程序备份已准备。启用仍是下一步，需要用户明确决定，因为它会更换日常运行程序，并需要重新打开 DSH；这不是重新审批开发计划。

若需要回退，先退出候选运行程序，恢复启用前备份中的源码、原插件、技能入口、profile/hooks 和原生问题客户端；移除仅属于候选新增的 4 个程序模块。保留业务数据库、已有回答及所有产物，不用重置数据库来回退代码。必要时从验收标签另建独立目录恢复程序；不要对正在使用的目录执行 `git reset --hard` 或清理输出。回退后用原任务编号查询状态，并如实处理来源或位置变化产生的必要确认。
